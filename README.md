<h1>Wide Coverage Location</h1>

<p>Projeto Wide Coverage Location, desenvolvido durante o módulo de CSS Intermediário do DevClub, com o objetivo de aprofundar os conhecimentos em HTML5 e CSS3 e desenvolver uma interface moderna e responsiva.</p>

<p>O projeto foi desenvolvido colocando em prática conceitos de layout, posicionamento, responsividade e organização de elementos, evoluindo os conhecimentos adquiridos durante os módulos anteriores.</p>
